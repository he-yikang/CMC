# CMC · 全国大学生数学竞赛真题与知识地图

> 非数学类（第一至第十七届）**42 套试卷 / 272 道大题**的可视化题库。
> 知识地图按学科并置两套考纲：**高等数学 9 个模块 / 63 个考点**、
> **线性代数 6 个模块 / 27 个考点**，共 **90 个考点**，
> 再配 **98 张公式 / 定理 / 性质 / 解题方法卡片**，与真题双向对应。

纯静态站点，无构建步骤，可直接用 GitHub Pages 托管。

## 功能

| 模块 | 说明 |
| --- | --- |
| **总览** | 数据概览、2009–2026 竞赛时间轴、高频考点 Top10、模块题量环图 |
| **首页动态视觉** | 首屏 hero 内置实时渲染的数学动效层：粒子网络、漂浮公式碎片、单位圆动点与尾迹、李萨如曲线、流动正弦波、刻度环、扫描光带；文字所在左半区自动压淡保证可读，右上角可暂停/播放，离开首页自动停止；尊重系统「减少动态效果」偏好 |
| **历届真题** | 42 套试卷卡片，可按阶段（初赛/补赛/决赛）、组别（A/B）、年份、关键词筛选 |
| **试卷详情** | 逐题列表（题号、题型、分值、考点标签、**原卷裁切小图**）+ 右侧**单题阅读**：点任意一题，只裁切渲染这一题的题目与参考解答，自动拼好跨页内容；可一键切到「**整卷**」看原版页面 |
| **整卷模式** | 翻页被限制在**本套试卷内**：先本套题目页、再本套参考解答页（如 17B决 = P98–P100 + P314–P318，共 8 页）。页码显示「本套第几页 / 共几页」并标注「题目 · P98」「参考解答 · P314」；越界翻页只提示不越界，PDF 内部链接若指向本套之外（如总目录）会被拦截并提示 |
| **PDF 原生链接** | 在 pdf.js 画布上叠加链接注解层：目录页的「题目 / 解答」页码、题目页右上角「参考解答(1初.1)」、解答页右上角「返回题目(1初.1)」都可直接点击跳转；热区已适度放大到 18×14px 并带悬停高亮 |
| **知识地图** | 按学科分弧的星系图（高等数学 1–9 / 线性代数 1–6，组间留空隙）、树状图、模块 × 届次热力图；**点击节点右侧栏原地切换**为该考点的考纲原文、相关卡片与对应考题（题目/解答按钮直接打开 PDF），不再跳走；可按「学科 / 模块」二级筛选 |
| **线性代数** | 独立学科（模块 1–6，27 个考点，逐条转录自《线代考纲》）；按用户逐届核对的 2014–2026 共 15 届决赛真题清单显式标注 21 道大题，`一(4)` 等标记表示填空题第 4 小题 |
| **知识卡片** | 知识地图第 4 个标签页：98 张卡片按「公式 / 定理 / 性质 / 解题方法」四类分色，公式由 KaTeX 排版；可按类型、模块、关键词筛选，点击卡片看条件、要点、匹配依据与关联真题 |
| **卡片详情** | 大号公式、条件与适用、使用提示/易错点、对应考纲考点、关联真题年度分布、自动匹配关键词、关联真题表（可直接打开 PDF 对应页） |
| **考点详情** | 考纲原文、年度/阶段分布、自动标注依据（关键词与权重）、相关卡片墙、关联试题表（可直接打开 PDF 对应页） |
| **统计分析** | 模块题次、试卷阶段/题型环图、逐年试卷数与大题数、高频考点、模块 × 届次热力图 |
| **考纲全文** | 按学科分栏：高等数学（9 模块，含补充专题）/ 线性代数（6 模块），共 90 个考点逐条列出 |
| **全文检索** | 同时检索试题（题干+解答摘要）、试卷、考点；`/` 键聚焦搜索框 |

题目与解答**从 PDF 原件裁剪渲染**（保留全部公式、图形与排版）：`build_data.py` 用页面右上角的
「参考解答(1初.1) / 返回题目(1初.1)」锚点算出每道题在页面上的矩形范围，前端按需把该区域从页面缓存里裁出来；
一道题跨页时按顺序拼成多段竖排，因此既不会带入别的题，也不会出现文本抽取的公式错位。
并在画布上重建了 PDF 的链接注解层，所以原件自带的目录页码与「双向跳转」编号仍然可用；
站点本身只负责索引、跳转和可视化。

**题目一律用裁切图显示，不用抽出来的文本**。原因是 LaTeX 把行内公式打散成基线不同的独立文本块，
`get_text()` 取回来必然是「e^x 变成 ex、分数上下叠成一行」这种错位，靠字号/基线去猜上下标又会把
`e^x` 猜成 `e_x` —— 只靠文本层救不回来。因此试题列表、考点表、卡片表、搜索结果里的「题目」列
都直接画该题在 PDF 上的原区域（`thumb` / `thumbS`，进入视口才渲染，串行排队）。

抽出的纯文本仍然保留（`stem` / `excerpt` / `solution`），只用于全文检索与考点自动标注；
这份 PDF 的数学字母是 Unicode「数学斜体」区（U+1D400 段），普通字体没有字形，直接显示就是豆腐块，
大号括号又来自 TeX 的 `txexs` 字体，被导出成 `\x00`–`\x1b` 控制字符与私用区码位 ——
所以入库前会用 `norm_text()` 做 NFKC 折叠与定界符还原，保证检索能命中、标注不出偏差。

## 数据来源与对应关系

1. `assets/cmc-papers.pdf` — 《全国大学生数学竞赛历届真题与详解》（第一至第十七届，
   非数学类，含初赛/补赛/决赛，共 318 页、42 套试卷、272 道大题，题目与解答双向索引）。
2. `scripts/syllabus_source.json` — 两套考纲的逐条转录：`CMC非数A高数考纲.docx`（M1–M8，另加 M9 补充专题）
   与 `CMC非数A线代考纲.docx`（L1–L6，6 模块 27 条），并为每个知识点配置关键词与权重。
3. `scripts/cards_source.json` — 人工整理的 98 张知识卡片（38 公式 / 20 定理 / 19 性质 / 21 解题方法），
   按 10 个模块组织，含 LaTeX 公式、条件、要点与匹配关键词。
4. `scripts/papers_source.json` — 42 套试卷的元数据（标号、年份、届次、阶段、组别、题目页/解答页区间），
   由原书总目录核对后固化，`build_data.py` 直接读取，不再解析总目录。
5. `scripts/paper_codes.json` — 旧「卷序 01–42」到新标号的映射，供 PDF 改写与数据生成共用。
6. `scripts/relabel_pdf.py` — 把 PDF 里的旧标号整体改写为新标号（页眉、交叉引用、总目录），
   用思源黑体 400 裁剪出的子集补字、西文用 Times，改完再把被涂改清掉的 1573 条链接注解原样补回。
7. `scripts/build_data.py` — 按版面位置（而非文本流顺序）识别 272 组「参考解答(标号.题号) / 返回题目(标号.题号)」
   锚点，切分题干与解答，按关键词规则自动标注考点与知识卡片，生成 `assets/data/*.json` 与 `bundle.js`。
   线性代数模块不参与自动标注，完全由 `LINALG` 清单（用户逐届核对）显式驱动。

### 试卷标号规则

`届数` + （`A`/`B`，仅当年分 A/B 类时写）+ `初`/`决`，补赛单独标注：

| 例 | 含义 |
| --- | --- |
| `1初`、`13初` | 第 1 / 13 届初赛（当年不分 A/B） |
| `15A初`、`17B决` | 第 15 届初赛 A 类；第 17 届决赛 B 类 |
| `13初（补）` | 第 13 届初赛补赛 |
| `14初（补1）`、`14初（补2）` | 第 14 届初赛第一次 / 第二次补赛 |

题目编号沿用「标号.题号」，如 `17A决.5` 表示 17A决 这套试卷的第五题（原「卷序 41.5」）。
PDF 内的页眉、交叉引用与总目录都已按同一规则改写。

生成的数据：

| 文件 | 内容 |
| --- | --- |
| `assets/data/papers.json` | 42 套试卷（年份、届次、阶段、组别、题目页、解答页、题数） |
| `assets/data/questions.json` | 272 道题（题号、题型、分值、题目页、解答页、题干、考点、单题裁切段 `qSegs`/`sSegs`、列表缩略图 `thumb`/`thumbS`） |
| `assets/data/syllabus.json` | 高等数学 9 模块 63 点 + 线性代数 6 模块 27 点，共 15 模块 / 90 知识点 |
| `assets/data/topics.json` | 知识点 → 试题映射及年度/阶段/届次统计 |
| `assets/data/cards.json` | 98 张知识卡片及其关联真题、匹配依据、年度分布 |
| `assets/data/bundle.js` | 以上数据的 `<script>` 版本，免 fetch，静态托管即可用 |

重新生成（修改考纲关键词、增删卡片或替换 PDF 后）：

```bash
pip install pymupdf
python scripts/build_data.py
```

**标注说明**：考点与卡片的对应均由关键词规则自动匹配，并对少量边界题做了人工校正，另有 21 道线性代数题按用户清单显式标注
（见 `scripts/build_data.py` 的 `OVERRIDES` / `LINALG`）；卡片可用 `must` 字段人工指定代表性真题。
一道题可归入多个考点与多张卡片，因此各分项之和大于 272。
结果：272 道题**全部**至少关联 2 张卡片，98 张卡片**每张**至少关联 5 道真题。
考点详情页与卡片详情页都列出「自动标注依据 / 匹配依据」，便于核对与人工修订。

## 备注

- 全站零外部依赖、零 CDN：pdf.js、KaTeX、字体表、数据、原件全部随仓库提供。
- 卡片公式用 KaTeX 渲染；说明文字里的行内公式由 `clean_inline()` 转成可读 Unicode，避免页面出现 LaTeX 源码。
- **关于 PDF 内部链接**：pdf.js 默认只绘制页面内容，不渲染 `/Annots` 链接注解，所以直接渲染时目录页码点了没反应。
  本站用 `page.getAnnotations()` 取出 `Link` 注解，按 `viewport.convertToViewportRectangle()` 换算成屏幕坐标，
  铺一层透明可点热区（`GoTo` 目标经 `getDestination` / `getPageIndex` 解析为页码），因此原件内的双向跳转得以保留。
- **PDF 已清理**：原件每页页脚的「清疏竞赛考研数学」水印已用 MuPDF 文本涂除（316 页，页数与 1573 条内部链接均保持不变）。
  清理脚本见 `scripts/clean_pdf_watermark.py`，可直接复用到更新后的原件。
- PDF 原件为第三方汇编资料，仅用于个人学习与复习；站点在页脚保留了资料出处，公开托管前请自行确认分发权限。
- 若页面显示「无法载入 PDF」，说明当前不是通过 HTTP 打开的，请改用本地服务器或 GitHub Pages。
