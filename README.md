# CMC · 全国大学生数学竞赛真题与知识地图

> 非数学类（第一至第十七届）**42 套试卷 / 272 道大题**的可视化题库，
> 并把每一道题挂到《CMC 非数 A 高数考纲》的 **8 大模块 / 62 个考点**上，
> 再配 **94 张公式 / 定理 / 性质 / 解题方法卡片**，与真题双向对应。

纯静态站点，无构建步骤，可直接用 GitHub Pages 托管。

---

## 在线预览

- 本仓库开启 GitHub Pages 后访问：`https://he-yikang.github.io/CMC/`
- 本地预览（**必须走 HTTP**，`file://` 下 pdf.js 无法读取 PDF）：

```bash
cd CMC
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/
```

## 功能

| 模块 | 说明 |
| --- | --- |
| **总览** | 数据概览、2009–2026 竞赛时间轴、高频考点 Top10、模块题量环图 |
| **历届真题** | 42 套试卷卡片，可按阶段（初赛/补赛/决赛）、组别（A/B）、年份、关键词筛选 |
| **试卷详情** | 逐题列表（题号、题型、分值、考点标签、题干摘要）+ 右侧 PDF 原卷阅读器；**看题目 / 看解答一键双向跳转** |
| **知识地图** | 星系图（可缩放拖拽、节点大小=关联题数）、树状图、模块 × 届次热力图；点击考点查看考纲原文、相关卡片与全部关联试题 |
| **知识卡片** | 知识地图第 4 个标签页：94 张卡片按「公式 / 定理 / 性质 / 解题方法」四类分色，公式由 KaTeX 排版；可按类型、模块、关键词筛选，点击卡片看条件、要点、匹配依据与关联真题 |
| **卡片详情** | 大号公式、条件与适用、使用提示/易错点、对应考纲考点、关联真题年度分布、自动匹配关键词、关联真题表（可直接打开 PDF 对应页） |
| **考点详情** | 考纲原文、年度/阶段分布、自动标注依据（关键词与权重）、相关卡片墙、关联试题表（可直接打开 PDF 对应页） |
| **统计分析** | 模块题次、试卷阶段/题型环图、逐年试卷数与大题数、高频考点、模块 × 届次热力图 |
| **考纲全文** | 逐条转录的 8 大模块 62 个考点，另设「补充专题」收纳跨章节方法与真超纲试题 |
| **全文检索** | 同时检索试题（题干+解答摘要）、试卷、考点；`/` 键聚焦搜索框 |

题目与解答**以 PDF 原件按页高保真渲染**（保留全部公式、图形与排版），
站点本身只负责索引、跳转和可视化。

## 数据来源与对应关系

1. `assets/cmc-papers.pdf` — 《全国大学生数学竞赛历届真题与详解》（第一至第十七届，
   非数学类，含初赛/补赛/决赛，共 318 页、42 套试卷、272 道大题，题目与解答双向索引）。
2. `scripts/syllabus_source.json` — 从 `CMC非数A高数考纲.docx` 逐条转录的考纲条目，
   并为每个知识点配置关键词与权重。
3. `scripts/cards_source.json` — 人工整理的 94 张知识卡片（36 公式 / 20 定理 / 18 性质 / 20 解题方法），
   按考纲模块组织，含 LaTeX 公式、条件、要点与匹配关键词。
4. `scripts/build_data.py` — 解析 PDF 总目录与 272 组「参考解答(卷序.题号) / 返回题目(卷序.题号)」
   交叉引用，切分题干与解答，按关键词规则自动标注考点与知识卡片，生成 `assets/data/*.json` 与 `bundle.js`。

生成的数据：

| 文件 | 内容 |
| --- | --- |
| `assets/data/papers.json` | 42 套试卷（年份、届次、阶段、组别、题目页、解答页、题数） |
| `assets/data/questions.json` | 272 道题（题号、题型、分值、题目页、解答页、题干、解答摘要、考点） |
| `assets/data/syllabus.json` | 8 考纲模块 + 1 补充模块、62 + 2 知识点 |
| `assets/data/topics.json` | 知识点 → 试题映射及年度/阶段/届次统计 |
| `assets/data/cards.json` | 94 张知识卡片及其关联真题、匹配依据、年度分布 |
| `assets/data/bundle.js` | 以上数据的 `<script>` 版本，免 fetch，静态托管即可用 |

重新生成（修改考纲关键词、增删卡片或替换 PDF 后）：

```bash
pip install pymupdf
python scripts/build_data.py
```

**标注说明**：考点与卡片的对应均由关键词规则自动匹配，并对 5 道超纲/边界题做了人工校正
（见 `scripts/build_data.py` 的 `OVERRIDES`）；卡片可用 `must` 字段人工指定代表性真题。
一道题可归入多个考点与多张卡片，因此各分项之和大于 272。
结果：272 道题**全部**至少关联 2 张卡片，94 张卡片**每张**至少关联 5 道真题。
考点详情页与卡片详情页都列出「自动标注依据 / 匹配依据」，便于核对与人工修订。

## 目录结构

```
index.html                      单页应用外壳（hash 路由）
assets/css/style.css            深色科技风样式
assets/js/app.js                路由、视图、图表、知识地图、PDF 阅读器
assets/js/pdf.min.js            pdf.js 3.11.174（本地内置，无 CDN 依赖）
assets/js/pdf.worker.min.js
assets/js/cmaps/                CJK CMap 字体表（168 个 .bcmap）
assets/js/katex/                KaTeX 0.16.11（js / css / 20 个 woff2 字体）
assets/cmc-papers.pdf           真题与详解原件
assets/data/                    结构化数据（含 cards.json）
scripts/syllabus_source.json    考纲 + 关键词规则
scripts/cards_source.json       94 张知识卡片（LaTeX 公式 + 匹配关键词）
scripts/build_data.py           数据生成脚本
```

## 备注

- 全站零外部依赖、零 CDN：pdf.js、KaTeX、字体表、数据、原件全部随仓库提供。
- 卡片公式用 KaTeX 渲染；说明文字里的行内公式由 `clean_inline()` 转成可读 Unicode，避免页面出现 LaTeX 源码。
- PDF 原件为第三方汇编资料，仅用于个人学习与复习；公开托管前请自行确认分发权限。
- 若页面显示「无法载入 PDF」，说明当前不是通过 HTTP 打开的，请改用本地服务器或 GitHub Pages。
